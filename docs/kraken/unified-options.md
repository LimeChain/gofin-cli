# Kraken unified option translation inventory

Explicit source option translation inventory. Fin exposes closed native operations, not a raw CCXT object/params API; caller transformations and unsupported aliases are labeled separately.

Every declared parameter in the 71 pinned overrides is listed in the machine inventory, along with source-signature arguments omitted from nearby comments, processed source options and inherited/emulated capability arguments. Pointers are checked against actual closed Fin input definitions. Quantities use explicit native units; Fin never applies CCXT precision rounding or treats arbitrary params as authority.

Finite native request mapping is implemented separately from CCXT aliases, response normalization and automatic pagination. Native equivalent fields are marked explicit_native_input_required. Response filtering/pagination/endpoint composition is caller-side-required. Incomplete or unavailable native pointers remain explicit; this inventory does not claim those aliases are executable broker inputs.

Current Futures fees require the related authenticated Spot GetTradeVolume route with futures_contract pair class. Deprecated Futures schedules are informational reads. Index candles use native spot. Transfer-out delegates preserve the product's exact direction and separately verified destination custody.

python3 scripts/audit-kraken-unified-options.py
